Допущения:
1) В логе обязательно должен быть статус оружия, иначе выводится ошибка и урон игрока считается 0
2) Если гильдия == '' или [], то такая гильдия считается как [Empty Guild]
3) weapon_states = {
    'active': 1.5,
    'broken': 0.5,
    'overheated': 0.7,
    'destroyed': 0.1,
    'repairing':0.3   
} - Словарь с кожффициентами для урона
4) Существует отрицательный урон
5) Если баффов больше одного, то все они суммируются
6) Если количество баффов (как значение) < 0, то берется модуль этого бафа. Это обусловленно тем, что поле под бафы называется "количеством бафов". Отрицательного количества быть не может, так что здесь либо брать модуль либо вызывать ошибку.
